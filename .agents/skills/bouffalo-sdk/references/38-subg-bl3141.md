# Sub-G 与 BL3141

`CONFIG_SUBG` 默认关闭，启用后编译 `components/wireless/bl3141_drv`。当前路径的主 MCU 通过 SPI 和 NIRQ、FIFO_EXH、shutdown GPIO 控制外接 BL3141 收发器；已检视示例演示原始数据包收发，不能据此宣称存在完整的 Sub-G 网络协议栈。驱动的 802.15.4 模式名本身也不证明完整协议栈。

`bl3141_hal/bl3141_hal.h` 提供 `bl3141_init()`、配置 get/set、休眠、接收、RSSI、发送和事件回调。初始化返回 `void`，ID 不符只打印错误，调用方不能从返回值判断初始化成功。默认 915.2 MHz、50 kbps、GFSK；当前 HAL 配置约束为 900–930 MHz、1250–2000000 bps，低层 API 注释中的其他范围不代表当前 HAL 或具体硬件已支持。FIFO 128 字节，最大包 2047 字节；发送超过上限会截断，发送时先停止接收。时序及事件、缓存生命周期以具体代码为准。

`port/mcu_port_config.h` 仅在 BL616 分支定义 SPI 1 MHz 和 GPIO；将板级引脚与真实接线核对，不应照搬。`examples/bl3141/bl3141` 以按键发送固定包、接收匹配前缀后控制 LED；`bl3141_cli` 提供射频收发配置和控制命令。示例 README 声明主控 BL616/BL618，不能将它们等同 BL618DG。实际频段、功率及射频发射需要按设备和使用地规定确认。

编译只能验证软件链路，实际验证需要接线正确的收发器、合适的对端和射频环境，分别检查初始化、发送完成、接收内容和异常处理。
